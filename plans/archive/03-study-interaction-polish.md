# 学习交互与高亮深度优化

## 目标

修复我历次「深度交互」板块列出的遗留问题、深化学习交互体验、完善高亮规则与展示、让学习规则引导更易懂。

## 范围

- 包含：高亮词形规则补全（双写辅音 -ing/-ed）与测试；`ExpressionStudyGuide` 文案细化与窄屏默认折叠；学习对话框的键盘快捷键（空格揭示、1/2 自评）、即时反馈与学后去向提示；分组按名称唯一在 state/merge 层校验；测试与文档同步。
- 不包含：删除或新增学习方式；改动记忆/复习算法契约；改动导入/数据库链路。

## 实施任务

- [x] 完善高亮规则（双写辅音词形）与展示一致性
- [x] 学习规则引导文案更易懂，窄屏默认折叠
- [x] 深化学习交互：键盘快捷键、即时反馈、学后去向提示
- [x] 修复遗留：分组重名在 state/merge 层校验

## 风险与回滚

- 风险：高亮泛化可能误命中无关表达（只加确定性词形规则）；分组名称唯一做成存储层不变量会改 merge 语义（按同名 LWW 去重）；快捷键可能与输入框/按钮焦点冲突（焦点在控件上时跳过）。
- 回滚：改动集中在 lib/features/测试/文档，逐文件 git revert 即可，无 schema 迁移。
