# 界面规范

> 状态：当前设计系统约束
> 产品工作流见 [详细设计](detailed-design.md)。

## 设计原则

- 学习工作区优先展示状态、内容和下一步动作，不使用营销式大标题。
- 主色仅用于关键操作和当前状态；掌握状态使用青绿色。
- 信息通过分隔线、间距和排版建立层级，避免页面由大量悬浮卡片组成。
- 页面顶部与工作区内的语义 header 不使用边框，层级由背景、间距和排版建立。
- 详情文本完整展示，不使用行数截断；列表标题可单行截断以保护布局。
- 桌面端使用顶部栏加可折叠侧栏，移动端使用左侧 Sheet 导航。

## 色彩

| Token | 用途 |
| --- | --- |
| `background` | 暖白主背景 |
| `foreground` | 深墨正文与高优先级操作 |
| `primary` | 珊瑚红主操作、当前进度 |
| `secondary` | 次级区域与消息背景 |
| `#258a72` | 已掌握、成功和稳定提升 |
| `success` | 成功 Toast 与同步完成 |
| `warning` | 警告 Toast |
| `destructive` | 错误 Toast 与破坏性操作 |

颜色必须通过语义 token 或业务状态变量引用，不在 shadcn 组件上覆盖默认文字样式。

## 排版

- UI 正文：Noto Sans SC。
- 学习标题与英文句子：Noto Serif SC。
- 日期、级别、编号和数据：IBM Plex Mono。
- 页面标题使用 `24–30px`；面板标题使用 `14–20px`。
- 字间距固定为默认值，不跟随视口缩放。

## 组件与交互

- 按钮图标使用 Lucide，并设置清晰的 `aria-label` 或可见文字。
- 主要列表支持整行点击；末尾箭头仅用于强化方向。
- 场景库使用紧凑响应式卡片网格展示 101 个场景；卡片图片从项目本地加载，并展示任务、
  标签、词汇、进度与时长。
- 场景分类和语言等级都允许多选；等级在列表和卡片中统一使用 Badge。
- 场景筛选工具栏随页面滚动吸顶，不增加无意义的边框。
- 二元设置使用 Switch，有限选项使用 Select 或 Tabs，数值范围使用 Slider。
- Dialog 与 Sheet 必须包含可访问标题和描述。
- 英文发音按钮紧随音标或句子，不独占新行。
- 输入错误通过 `Field` 的 `data-invalid` 和控件的 `aria-invalid` 表达。
- 对话页以转写内容为首屏主体，辅助提示默认折叠并按需展开。
- 转写滚动区自己持有顶部内边距，不靠内部元素的 `py` 撑开，否则首轮会贴住上方的会话指标条；
  横向内边距与指标条一致，使转写区不显得比同列其他区域更窄。
- 实时语音和文字输入互斥；语音模式中不显示可提交的文字输入框。
- `InputGroup` 原语在任一后代为 `disabled` 时会把整组降到 50% 不透明度并染色。当组内只有
  发送按钮随草稿为空而禁用时，必须在调用处覆盖 `has-disabled:opacity-100` 与
  `has-disabled:bg-transparent`，否则整个输入区会被误读为不可用。禁用表达只属于真正被禁用的
  那个控件。
- 用户消息不显示阻塞式验证状态；表达问题随下一条 AI 回复直接反馈。
- 对话反馈标注输入语言与意图；仅英文产出问题使用错误状态，中文翻译请求使用表达参考。
- 错误反馈完整展示用户原句、错误片段、替换内容与原因；巩固例句直接展示且支持发音。
- AI 对话主气泡只展示英文；中文翻译、记忆提示和学习建议放入独立辅助区域。
- 英文回复里的列表、引用表达等特殊内容渲染为结构化样式，不直接暴露 Markdown 符号。
- 语音模式持续显示“可以说话、正在思考、正在回应、已静音”等明确状态。
- 焦点短语同时展示沟通动作、英文表达和中文使用含义；对话产生的新焦点去重后累加在顶部。
- 地道表达使用独立菜单和连续行列表，完整展示语境、含义、解释、来源和例句；搜索、来源
  与多选场景筛选不得隐藏匹配总数。筛选区吸附在全局顶栏下方，长列表由底部哨兵无限滚动
  加载，不显示手动分页或“加载更多”按钮。
- 对话提示栏不嵌入完整词库，只提供进入独立表达库的紧凑链接。
- 表达导入弹窗提供“粘贴 JSON / 上传文件”两个 Tab，不提供逐条字段表单；JSON 自动校验，
  并使用固定高度的 Monaco Editor；文件入口提供 CSV 模板。预检结果使用单行紧凑统计，
  保存状态明确区分本机与云端。用户导入项排在内置项之前，并提供行级编辑和删除图标；
  内置表达保持只读。
- 对话工作区铺满内容区域，不添加装饰性外框；桌面提示栏支持拖拽调宽，分隔线贯穿并对齐。
- 顶部搜索使用全局 Dialog；桌面显示完整搜索触发器，移动端显示搜索图标，结果按页面、
  学习场景和学习记忆使用横向 Tabs 筛选，整行作为主操作；结果区域必须在弹窗内独立滚动。
- 搜索快捷键使用 `24px`、字号至少 `12px` 的一致独立键帽，并明确显示组合键连接符。
- 句子类型使用单行横向 Tabs；分类栏滚动到工作区顶端后吸附在全局顶栏下方，激活项在
  深浅主题中都必须有可辨识的边界和底色。
- 全局顶栏及吸顶筛选栏使用不透明主题背景，页面滚动时不得透出下层内容；共享页面 Header
  不设置底部 padding，由页面模块的 gap 负责间距。
- 新问句和回答只向下滚动到转写区上边缘，已经位于上边缘附近时不反向滚动。
- 模型配置列表与编辑表单互斥显示；每条已保存配置提供行内验证入口并显示验证中、成功或失败
  状态；启用操作使用成功色，模型名使用主题化建议菜单，同时保留自由输入。
- 设置页将模型服务与学习策略合并为同一一级分区，并在桌面端使用等宽双列卡片；学习策略
  位于左列且字段纵向排列，模型服务位于右列；
  账户与数据卡片不超过内容宽度的一半。对话布局与输入方式在左列紧凑堆叠，
  会话与判句在右列跨两行，移动端全部回落为全宽单列。
- 系统发音在设置页统一配置并支持试听；影子跟读的 AI 角色沿用该音色，另一角色自动匹配
  同语种的不同音色。
- 设置卡片最大高度为视口可用高度与 `680px` 中的较小值；标题和底部操作保持可见，只有
  中间内容区在超出最大高度时滚动。
- 空白、纯符号和语气词 ASR 结果不形成对话；会话续接、连续提问合并和语音判句等待可在设置中调整。
- TTS 播放期间暂停 ASR 音频采集，播放完成后才恢复，避免扬声器回声被识别为用户回答。
- 长期记忆完整展示来源、调度、历史表现和全部迁移目标，不使用折叠详情。
- 智能复习使用一个连续工作区承载队列、当前任务、评分和学习证据，避免嵌套卡片。
- 智能复习从 `lg` 断点开始使用左队列、中任务、右证据三栏布局，各栏独立滚动。
- 桌面侧栏底部展示真实平均记忆强度、记忆数量与练习次数，不显示无语义的孤立计数。
- Toast 根据内容自适应宽度，成功、警告和错误分别使用绿、黄、红状态色。
- 影子跟读左侧场景队列支持整行切换，主区域保留听对话、跟角色、去应用三阶段；预设内容
  使用多轮对话，标题明确标记预设、生成或记忆定制来源；任意台词都可成为跟读目标，并支持
  互换角色。
- 影子跟读翻译默认关闭；中栏内容独立滚动，操作区吸附底部。重新录音单击后立即开始，
  同一句的临时录音在页面会话内保留并显示分数变化，离开页面后统一释放。桌面中栏占满页面
  标题后的剩余高度，长脚本不得推走底部操作区。
- 影子跟读“跟角色”阶段默认开启自动接话：进入阶段先播对方上一句，录完自动播对方回应并把
  目标推进到本角色下一句，形成可听见的对话节奏；工具栏 Switch 可关闭并回到手动选句。
  对方播报期间禁用录音，底部固定提示当前处于“对方接话”还是“该你开口”。
- Workspace 首页使用响应式瀑布流展示计划、记忆、场景、练习构成和迁移目标；推荐区使用
  主题语义色，不使用固定深色反白。

## 响应式

- 最小支持宽度为 `320px`。
- `lg` 以下隐藏桌面侧栏并显示移动导航。
- 双栏工作区在窄屏改为单栏，控制区允许换行。
- 固定格式的波形、图表和进度条使用明确高度，动态内容不改变整体布局。
- 场景卡片在手机、平板、桌面、宽屏分别使用 1、2、3、4 列。
- 必须在 390px 宽度检查对话头部、输入控制、复习评分和记忆指标。

## 动效

- 侧栏宽度变化使用 200ms 过渡。
- 对话等待状态使用三个错峰圆点。
- 语音 Agent 使用 GSAP 驱动轨道、扫描线、核心脉冲与音量条，动画不改变布局尺寸。
- 波形播放与录音使用轻微脉冲，不改变元素尺寸。
- 所有交互遵循 `prefers-reduced-motion` 的浏览器默认降级。

## 组件所有权

- `components/ui`：shadcn/Base UI 原语，只包含通用交互与主题样式。
- `components`：跨 feature 的应用外壳、导航、品牌和 Provider。
- `features/<name>`：业务工作区、业务组合组件和 feature hook。
- 页面文件只负责 metadata、参数解析和工作区组合，不复制 feature UI。

## 视觉验收

每次视觉变更至少检查桌面与 `390px`：

1. 页面 `scrollWidth` 不大于视口宽度。
2. 焦点顺序、可访问名称、Dialog/Sheet 标题完整。
3. loading、empty、disabled、error、active、complete 状态尺寸稳定。
4. 长英文、中文、数字和错误信息在按钮、表格与面板内正常换行。
5. 语音动画在 `prefers-reduced-motion` 下仍提供清晰文本状态。
